# عز الدمشقي — نسخة Vercel

## النشر على Vercel

1. ارفع مجلد المشروع إلى GitHub أو ارفعه مباشرة إلى Vercel.
2. اختر Framework Preset: **Vite**.
3. اترك Build Command كما هو: `npm run build`.
4. اترك Output Directory كما هو: `dist`.
5. لا تستخدم `server/index.ts` ولا أمر `pnpm start` في Vercel.

الصور موجودة داخل `client/public/images` وتعمل بدون روابط Manus الخاصة.
